# Документы студенческого репозитория

Раньше в этом файле лежала инструкция для студентов, которая целиком
копировалась в `README.md` шаблона. Теперь документов три, и каждый
хранится отдельным файлом-источником:

| Источник | Куда попадает в шаблоне | Кто редактирует |
|---|---|---|
| `admin/template-README.md` | `README.md` | заготовка; заполняет студент |
| `admin/template-TASK.md` | `TASK.md` | преподаватель |
| `admin/template-GUIDE.md` | `GUIDE.md` | преподаватель |

## Что в каждом файле

**`README.md`** — титульная страница репозитория студента: чей репозиторий,
ссылки на остальные документы, команды запуска и **описание варианта**
(свойства языка, типы, операции, функции). Заготовку с плейсхолдерами
заполняет студент. На этот файл опирается и преподаватель, и ИИ-ревью.

**`TASK.md`** — требования практикума: последовательность из пяти
лабораторных работ, структура отчёта, требования к разрабатываемому языку.
Составлен на основе корневого `TASKS.md` этого репозитория, но **без
таблицы вариантов** — конкретный вариант студент получает от преподавателя
и выписывает в свой `README.md`.

**`GUIDE.md`** — как работать: ветки `task<номер>`, Pull Request, правила
ИИ-ревью, локальная проверка, базовые команды git.

## Как обновить документы в шаблоне

`./manage.sh sync-workflow` синхронизирует только `.github/**`. Текстовые
документы копируются вручную:

```bash
TPL=/путь/к/клону/yapis-2026-template

cp admin/template-README.md "$TPL/README.md"
cp admin/template-TASK.md   "$TPL/TASK.md"
cp admin/template-GUIDE.md  "$TPL/GUIDE.md"

cd "$TPL" && git add -A && git commit -m "docs: обновить документы шаблона" && git push
```

> `README.md` перезаписывайте осознанно: в шаблоне это заготовка, но в
> репозитории студента там уже его собственный текст. Команда
> `sync-workflow` этот файл не трогает — и правильно делает.

## Важно про ссылки в промптах

Промпты ИИ-ревью ссылаются на `TASK.md` и `README.md` студента
(см. `COURSE_DOCS` в `.github/review/config.env` и файлы
`.github/review/tasks/*/prompt.md`). Если переименуете документы в шаблоне —
обновите и эти ссылки, иначе модель будет искать несуществующие файлы.
