## Как запустить

Компиляция программы выполняется скриптом `compile.sh` из корня репозитория:

```bash
./compile.sh examples/example1.txt
```

Скрипт принимает файл с текстом программы и генерирует запускаемый файл.
На примерах с ошибками он должен завершаться с ненулевым кодом и выводить
осмысленное сообщение (что нарушено и где).

## Проверить работу до отправки PR

Та же проверка, что запускается в Pull Request, доступна локально —
без ограничений по количеству запусков:

```bash
./review-local.sh
```

Подробности — в [`GUIDE.md`](GUIDE.md), раздел «Проверка работы локально».
