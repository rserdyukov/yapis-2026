# Состав template-репозитория студента.
#
# Единый источник правды: используется командой `./manage.sh sync-template`
# (раскатка источник -> шаблон) и тестом template_manifest_is_consistent
# в .github/review/tests/run-tests.sh.
#
# Формат строки:
#   <путь в этом репозитории> -> <путь в шаблоне>
#
# Пустые строки и строки, начинающиеся с #, игнорируются.
# Путь-источник может быть файлом или директорией; директория копируется
# целиком, кроме исключений (см. ниже).
#
# ВАЖНО. Инфраструктура ИИ-ревью (.github/review, workflow ai-review) в
# репозитории студента БОЛЬШЕ НЕ ЛЕЖИТ: ревью выполняется централизованно из
# приватного репозитория преподавателя (см. reviewer/ и admin/SETUP.md).
# Поэтому у студента остаются только его документы, скрипт локальной
# проверки и детектор прямых пушей в main.
# Состав репозитория ревьюера задаётся отдельно — admin/reviewer-manifest.txt.

# --- Документы студента ---
admin/template-README.md         -> README.md
admin/template-TASK.md           -> TASK.md
admin/template-GUIDE.md          -> GUIDE.md

# --- Инструменты студента ---
# Тонкий скрипт локальной проверки: сами проверки и промпты он скачивает из
# публичного репозитория курса в ~/.cache/yapis-review, поэтому обновлять их
# в репозиториях студентов не нужно.
admin/template-review-local.sh   -> review-local.sh

# --- Детектирующий контроль ---
# На плане Free защита ветки main для приватных репозиториев недоступна,
# поэтому прямые пуши ловятся этим workflow (issue + failing status).
.github/workflows/guard-main.yml -> .github/workflows/guard-main.yml

# --- Файлы, которые НЕ обновляются в репозиториях студентов ---
# Указываются путями в шаблоне. Их раскатывает только sync-template (в сам
# шаблон), а sync-workflow обходит стороной — иначе работа студента будет
# затёрта. Всё остальное из списка выше обновляется в обеих командах.
#
# README.md в шаблоне — заготовка, но у студента там уже его собственное
# описание варианта задания.
!STUDENT_KEEP README.md

# --- Файлы, которые нужно УДАЛИТЬ из репозиториев студентов ---
# Пути в репозитории студента, оставшиеся от прежней схемы, когда ИИ-ревью
# запускалось прямо у него. Сейчас ревью централизованное, и эти файлы не
# только не нужны, но и вредны: workflow ai-review.yml требовал секрет с
# ключом модели в репозитории студента.
#
# sync-workflow удаляет их тем же PR, что обновляет документы.
# После того как все студенты смержат PR, строки можно убрать отсюда.
!STUDENT_REMOVE .github/workflows/ai-review.yml
!STUDENT_REMOVE .github/review
