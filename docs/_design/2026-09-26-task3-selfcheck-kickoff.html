Engineering brief · 2026-09-26 · architectural

Самопроверка практической задачи 3 (LL(1)) с ответом на формальном языке

Студент решает практическую задачу 3 (грамматика → свойства → преобразование → FIRST/FOLLOW → таблица LL(1) → разбор трёх строк) и записывает ответ на маленьком DSL прямо на странице сайта. Страница проверяет ответ в браузере (Python-ядро в Pyodide) и даёт ступенчатую диагностику: сколько ошибок, где, почему (свидетель-вывод или контрпример), а по запросу — эталон элемента. Режим — формирующая самопроверка; сдача практики остаётся на бумаге.

Предлагаемое решение

Вариант A

Самопроверка без ставок (D1) снимает главный плюс C — закрытый эталон. Против B решает переиспользование ядра из Python в инкрементах 3–4 (перечисление языков, генератор, задел задач 2/4) и единые тесты с репо. Цену A — первая загрузка и CDN — принимаем с митигацией R2.

Критерий успеха: К занятию (< 2 недель) страница проверяет шаги 4–6 для любой введённой грамматики: исправленный пример варианта 8 даёт «ошибок нет», каждый мутант тестового набора находится и локализуется.

Границы задачи и ADR
  • оценки, контрольные, лимит попыток, закрытые эталоны
  • сбор статистики ошибок
  • сдача практики через PR (ветки task<N> заняты ЛР)
  • варианты 3, 4, 19–23 (картинки) — перевод в текст отдельной задачей
  • реализация задач 2 и 4 — только задел в модели ядра

не требуется — откат удалением строки nav и вызова хука, критерий «трудно откатить» не выполнен
