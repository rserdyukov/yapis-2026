# Редизайн сайта курса

## Согласованные решения

- Ветка работы: `github_pages`. Подключён каталог из коммитов до `d550afb`
  ветки `languages-catalog`; более поздние изменения ревьюера не переносились.
- Источник структуры: Obsidian Canvas `2026-09 Структура сайта по курсу.canvas`.
  Курс, каталог языков, концепции дизайна и цифровой сад — четыре направления.
  Онтология остаётся одной страницей с входами из каталога и концепций.
- Визуальный ориентир: <https://thariqs.github.io/html-effectiveness/> —
  тёплый фон, терракотовый акцент, заголовки с засечками, карточки и большие отступы.
- Пользователь выбрал верхнее меню и карточки; боковые колонки убраны,
  оглавление встроено в статью. Контейнер 1280 px, обычный текст до 960 px.
  Смена генератора не требуется: MkDocs сохраняет поиск и проверку ссылок.
- Пользователь разрешил публикацию текущих материалов и подключение каталога.
  Будущие разделы показываются как план развития без пустых ссылок.
- Публикация — только с YAML `publish: true`. Нет флага / `false` — черновик.
  Для карточек языка источником остаётся YAML; метаданные генерируемых индексов
  сохраняются при пересборке. Текст задания для студента от флага сайта не зависит.

## Проверки

- Готовая страница присутствует в HTML, поиске и sitemap; черновик отсутствует.
- После снятия флага повторная чистая сборка удаляет страницу и старые HTML колод.
- Опубликованные индекс и матрица каталога не ссылаются на скрытые карточки.
- Ссылка из готовой статьи на черновик останавливает strict-сборку.
- В браузере на 1440 / 768 / 390 px доступны верхнее меню, поиск и оглавление;
  страница не имеет горизонтального переполнения, широкие таблицы прокручиваются внутри.
