# Онтология v2: реальные языки первичны

## Решение и происхождение

Пользователь согласовал переход от свойств вариантов лабораторных к независимым
концепциям языков. Дополнительно потребовал учитывать исторические,
исследовательские и предметные языки, не ограничиваясь современными популярными.
Исследование и границы доказательности — в `language-research-map.md`.

Выбрана миграция существующего YAML-каталога: независимые ID, структурированные
контексты, отдельное отображение учебных пунктов. Простое дополнение старых
`variants.*` оставляло бы лабораторные первичными; переход на RDF/OWL сейчас не
нужен для статической матрицы и не исправляет неточные предметные определения.

## Изменение сценариев

- Автор описывает язык через общие концепции; `lab-mapping.yaml` ссылается на них.
- Карточки Java, Python, Rust мигрированы; добавлены восемь сравнительных карточек.
- Контекст различает язык, библиотеку, реализацию и инструмент; профиль по умолчанию
  наследуется при проверке и отображении. `since` включительно, `until` исключительно.
- Ограничение количества значений проверяется внутри структурированного контекста
  по пересекающимся интервалам. Для bool подразумевается одно активное значение.
- Отсутствующая запись означает неизвестность, false — отсутствие булева свойства,
  n/a — неприменимость с обязательным пояснением.
- Пример-витрина необязателен. Если файл или секция указаны, ссылка проверяется.
- Процент заполнения словаря информационный: языки не обязаны покрывать каждое значение.
- Публикация по `publish: true` сохранена; прежние якоря обеспечены legacy_slugs.

## Границы

74 концепции и 11 карточек — начальная проверенная структура, а не полная
энциклопедия. Публичная карта содержит 60 языков/семейств со статусом источников;
упоминание кандидата не равно готовой карточке. Восемь сравнительных карточек
пока не имеют примеров-витрин и извлечённых грамматик, что явно указано в тексте.
Новые 22 оси могут не иметь заполненных значений в текущих карточках.
Исходные условия и распределение вариантов лабораторных не изменены.

## Риски и проверка

| Риск | Контроль |
|---|---|
| Потеря старых ссылок | Тест рендеринга legacy/canonical якорей и strict MkDocs |
| Смешение разных версий и реализаций | Контекстные тесты, проверка default_profile и интервалов |
| Скрытое превращение неизвестности в false | Проверка пустой ячейки против false/n/a |
| Повреждённые кодовые примеры | Проверка файлов, секций, грамматик и лицензий |
| Ошибочный предметный факт при валидном YAML | Источники у утверждений; предметное ревью отделено от схемного |
| Ложная полнота широкого списка | Статусы подтверждено/частично/запланировано на карте |

Проверено: 206 тестов инфраструктуры, 21 тест каталога/публикации, strict-сборка,
shellcheck, браузерная геометрия 1440/768/390 px, поиск и навигация. Визуальная
оценка скриншотов не выполнялась. Коммиты и публикация этой миграции не выполнялись.
