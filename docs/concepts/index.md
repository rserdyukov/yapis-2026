# Концепции дизайна языков

Языки различаются не только синтаксисом. Исследуйте решения о типах,
памяти, областях видимости и ошибках — и смотрите, как они сочетаются в реальных языках.

<div class="grid cards" markdown>

- **[Онтология концепций](../languages/concepts.md)**

    Общий словарь и матрица «концепция × язык». Из каждого значения
    можно перейти к объяснению и примеру в карточке языка.

- **[Каталог языков](../languages/index.md)**

    Обратный маршрут: выберите язык и рассмотрите его свойства,
    грамматику, версии и примеры программ.

- **[Книги и ресурсы](../materials/index.md)**

    Литература курса, документация ANTLR и целевых платформ,
    инструменты для экспериментов.

</div>
