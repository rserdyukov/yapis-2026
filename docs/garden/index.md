# Цифровой сад

Статьи об идеях, которые языки программирования воплотили радикальнее других.
В каждой статье — проблема, которую решает идея, устройство на примерах кода с
результатом запуска, цена решения, сравнение с другими языками и выводы для того,
кто пишет собственный язык и компилятор.

<div class="grid cards" markdown>

- **[Rust: владение и заимствование](rust-ownership.md)**

    Освобождение памяти без сборщика мусора: один владелец у значения и
    статическая проверка ссылок компилятором.

- **[Go: сознательная бедность языка](go-simplicity.md)**

    Отказ от наследования, исключений и перегрузки как проектное решение
    для больших команд и кодовых баз.

- **[Lua: метатаблицы, язык как конструктор](lua-metatables.md)**

    Одна структура данных и перехват операций над ней — классы, прокси и
    перегрузку операторов собирает программист.

- **[Zig: comptime вместо макросов](zig-comptime.md)**

    Код времени компиляции на том же языке: типы как значения, обобщения
    как функции, никакого препроцессора.

- **[Forth: стек вместо синтаксиса](forth-stack.md)**

    Программа — поток слов, данные — на неявном стеке, компилятор
    расширяется обычными определениями.

- **[APL: нотация как инструмент мышления](apl-arrays.md)**

    Операции над целыми массивами и одно правило вычисления справа налево
    вместо уровней приоритета.

- **[SQL: декларативность](sql-declarative.md)**

    Запрос описывает результат, план выполнения выбирает оптимизатор.

- **[Erlang: модель ошибок «let it crash»](erlang-let-it-crash.md)**

    Изолированные процессы, которым разрешено падать, и супервизоры,
    которые их перезапускают.

- **[Smalltalk: всё есть сообщение](smalltalk-messages.md)**

    Единая объектная модель: условия, циклы и классы — не синтаксис,
    а посылки сообщений.

- **[Haskell: чистота и ленивость](haskell-purity-laziness.md)**

    Нестрогие вычисления, которые вынудили язык стать чистым, и цена
    этого решения.

- **[JavaScript: цена обратной совместимости](javascript-compatibility.md)**

    Выпущенное в веб поведение нельзя убрать — язык исправляет ошибки
    только добавлением нового.

</div>

## Как читать статьи

- **Статус примеров.** «Проверено» — пример запущен, вывод скопирован из запуска
  с указанием версии. «Не запускалось» — компилятора не было; ожидаемый результат
  выведен из документации, ссылка на раздел дана рядом. Учебные модели
  (`miniforth.py`, `miniapl.py`) — подмножества языков, написанные для статей;
  это не полноценные реализации.
- **Исходники.** Каждый пример — отдельный файл в
  [`docs/garden/src/`](https://github.com/rserdyukov/yapis-2026/tree/main/docs/garden/src);
  `run.sh` в папке статьи запускает все её примеры.
- **Связи.** Статья указывает языки [каталога](../languages/index.md) и
  [понятия онтологии](../languages/glossary.md), которые объясняет; на карточке
  языка и у понятия в словаре есть обратная ссылка на статью.
