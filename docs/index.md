# Языковые процессоры интеллектуальных систем

Сайт курса: задание лабораторного практикума, слайды лекций и
дополнительные материалы.

## С чего начать

Если вы только получили доступ к своему репозиторию:

1. Прочитайте [требования практикума](labs/index.md) — они одинаковы для всех.
2. Найдите свой номер в [таблице вариантов](labs/variants.md) и выпишите
   свойства языка в `README.md` своего репозитория.
3. Порядок работы с ветками, Pull Request и правила ИИ-ревью — в `GUIDE.md`
   вашего репозитория.

## Как устроена сдача работ

Одна лабораторная работа — одна ветка `task<номер>` и один Pull Request.
На каждый PR автоматически запускается предварительное ИИ-ревью; итоговую
оценку ставит преподаватель.

Подробности — в `GUIDE.md` вашего репозитория.
