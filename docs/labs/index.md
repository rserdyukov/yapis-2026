# Лабораторный практикум

Здесь описано, **что нужно сделать** и **каким требованиям** должен
удовлетворять разрабатываемый язык. Требования одинаковы для всех вариантов.

Конкретный вариант задания — язык, набор свойств и целевой код — выдаёт
преподаватель. Списки вариантов и таблица распределения: [Варианты
заданий](variants.md).

Порядок работы с репозиторием, ветки, Pull Request и правила ИИ-ревью
описаны в `GUIDE.md` вашего репозитория.

## 1. Последовательность лабораторных работ

**Лабораторная работа 1**
Написать три примера фрагментов кода языка по варианту:
1. Пример решения задачи из предметной области языка. Объем программы должен быть не менее 50 строк.
2. Пример со всеми вариантами синтаксических конструкций. Каждая конструкция должна быть прокомментирована.
3. Третий пример на ваш выбор. Рекомендую сделать небольшой пример для отладки грамматики.
Примеры разместить в папке examples
Заполнить в `README.md` своего репозитория раздел с вариантом задания, указать свойства разрабатываемого языка

**Лабораторная работа 2**
Составить файл грамматики с использованием ANTLR (можно отлаживать здесь:
[lab.antlr.org](http://lab.antlr.org/)), проверить на примерах из
лабораторной работы 1.

**Лабораторная работа 3**
Написать синтаксический анализатор, который выдаёт лексические и синтаксические ошибки; протестировать
на примерах из лабораторной работы 1 и на новых примерах, демонстрирующих
обработку ошибок. Имена файлов с примерами ошибок должны начинаться на "error-".
Нужно написать всю логику необходимую для запуска синтаксического анализатора с помощью команды `compile.sh <файл с примером>`

**Лабораторная работа 4**
Написать семантический анализатор, который выдаёт семантические ошибки; протестировать
на примерах из лабораторной работы 1 и на новых примерах, демонстрирующих
обработку ошибок. Добавить в `README.md` своего репозитория список семантических проверок/ошибок, которое поддерживает ваш компилятор

**Лабораторная работа 5**
Завершить написание компилятора, добавить логику генерации целевого кода для VM.
Подготовить отчёт.

> Одна лабораторная работа — одна ветка `task<номер>` и один Pull Request.
> Подробности в `GUIDE.md` своего репозитория.

## 2. Структура отчёта по лабораторному практикуму

Отчёт размещается в директории `doc/` и должен содержать:

1. Спецификация разработанного языка программирования.
   1. Синтаксис объявления переменных и подпрограмм.
   2. Синтаксис операций над данными (их должно быть не менее десяти).
   3. Синтаксис всех управляющих конструкций.
2. Оформленный (отформатированный и прокомментированный) файл грамматики (`.g4`).
3. Описание дополнительно разработанных классов.
4. Перечень генерируемых ошибок.
5. Примеры работы компилятора.

## 3. Требования к разрабатываемому языку

Эти требования обязательны для всех вариантов.

1. Встроенные типы — не менее трёх.
2. Возможность инициализации переменных всех типов при объявлении:
   `<тип>? <имя_переменной> = <выражение>`.
   1. Инициализирующее выражение может быть константным.
3. Встроенные операции — не менее десяти.
4. Встроенные функции.
   1. Встроенные функции ввода/вывода для работы со встроенными типами:
      `read()`, `write()`.
5. Использование сложных выражений (составных и со скобками).
6. Блочный оператор.
7. Управляющие структуры.
   1. Условный оператор (`if-then-else`).
   2. Операторы цикла (`while` и `until`).
   3. Оператор цикла с итерациями (`for`).
8. Пользовательские подпрограммы.
   1. Передача и возврат параметров.
   2. Задание локальной и глобальной области видимости для имён переменных.
