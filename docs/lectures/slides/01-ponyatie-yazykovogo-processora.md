# Понятие языкового процессора

---
## Что такое языковой процессор?
Программа, преобразующая входные данные, записанные на формальном языке, в другой вид данных или действий.

Обязательно включает проверку входных данных на соответствие формальному языку.

---
## Формальный язык
- Формальный язык и естественный язык (сравнение)
    - Количество вариантов интерпретации.  `Он рассказал другу, что его уволили.`
    - Четкие правила построения. Формальные грамматики

---
## Что может быть языком?
- Наскальные рисунки
- Нотная запись музыки
- Жесты, мимика
- «Сигналы» животных
- Сигналы светофора

*Дизайн-признаки языка Чарльз Хоккетт*
*Манускрипт Войнича*

---
## Синтаксис, семантика и прагматика языка
- Синтаксис — правила построения конструкций языка
- Семантика — описание того, как интерпретировать конструкции языка
- Прагматика — описание того, как использовать язык в конкретных ситуациях

---
## Типы языковых процессоров
- Транслятор
    - Компилятор
- Интерпретатор
- Статический анализатор

---
## <!--fit--> Примеры языковых процессоров для Python
- CPython. Компиляция в байт-код (.pyc) и исполнение в виртуальной машине
- PyPy. Альтернатива CPython с использованием JIT-компиляции
- Cython. Транслятор Python в C
- Pylint. Статический анализатор
- pydoc. Генерация документации

---
## <!--fit--> Примеры языковых процессоров для C++
- Компиляторы: Clang, Microsoft Visual C++ (MSVC)
- Статические анализаторы: Cppcheck, clang-tidy, PVS-Studio
- Генерация документации: Doxygen

---
## Цепочки языковых процессоров

- В TypeScript — преобразование в JavaScript и последующая интерпретация
- В Unity — C# преобразуется в C++
- … (домашнее задание)

## <!--fit--> Среда разработки и языковые процессоры
- Редактор исходного кода
- Комплекс языковых процессоров
- Инструменты автоматизации сборки
- Отладчик
- Динамические анализаторы

---
## <!--fit--> Типовая структура языкового процессора
- **Препроцессор**. Исходная программа → Модифицированная исходная программа
- **Компилятор**. Модифицированная исходная программа → Перемещаемый целевой код
- **Компоновщик/загрузчик**. Перемещаемый целевой код + библиотечные файлы → Целевой код

---
## Структура компилятора
- **Лексический анализатор**. Текст → Поток токенов
- **Синтаксический анализатор**. Поток токенов → Синтаксическое дерево разбора
- **Семантический анализатор**. Синтаксическое дерево разбора → Аннотированное синтаксическое дерево
- **Генератор промежуточного кода**. Аннотированное синтаксическое дерево → Промежуточный код
- **Оптимизация**. Промежуточный код → Промежуточный код
- **Генератор целевого кода**. Промежуточный код → Целевой код

---
## <!--fit--> Модули современного компилятора
- **Frontend**
    - Вход: исходный текст
    - Выход: промежуточное представление (Intermediate Representation, IR)
    - Задача: синтаксический и семантический анализ
- **Backend**
    - Вход: промежуточное представление
    - Выход: целевой код
    - Задача: оптимизация, генерация целевого кода

---
## Интерпретатор
- Простой или строчный интерпретатор
    - Прочитал строку — выполнил
    - REPL, Read-Eval-Print Loop
- Компиляция в байт-код и исполнение его в виртуальной машине
    - JVM
    - JIT, Just-In-Time

---
## Ключевые понятия
- Языковой процессор. Транслятор. Интерпретатор
- Формальный язык. Синтаксис. Семантика. Прагматика
- Структура компилятора. Frontend и Backend компилятора
