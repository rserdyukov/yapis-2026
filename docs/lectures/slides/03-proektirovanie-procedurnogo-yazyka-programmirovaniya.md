## <!--fit--> Базовые свойства проектируемого языка (1)
- Объявление переменных    
	- Явное    
	- Неявное
- Преобразование типов    
	   - Явное, например, `a = (int) b`    
	   - Неявное    
- Оператор присваивания    
	   - Одиночный, например, `a = b`    
	   - Множественный, например, `a, b = c, d`    

--- 
## <!--fit--> Базовые свойства проектируемого языка (2)
- Структуры, ограничивающие область видимости    
	- Подпрограммы    
	- Подпрограммы и блочные операторы    
- Маркер блочного оператора    
	- Явный, например, `{ }` или `begin end`    
	- Неявный, как в Python    
- Условные операторы
	- Двухвариантный оператор `if-then-else`    
	- Двухвариантный оператор и многовариантный `switch-case`

---
## <!--fit--> Базовые свойства проектируемого языка (3)
- Перегрузка подпрограмм    
	- Отсутствует    
	- Присутствует    
- Передача параметров в подпрограмму    
	- Только по значению и через возвращаемое значение    
	- По значению и по результату    
	- По ссылке    
- Допустимое место объявления подпрограмм:    
	- В начале программы    
	- В любом месте программы, а также внутри другой подпрограммы.
