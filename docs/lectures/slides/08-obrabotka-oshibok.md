# Обработка ошибок

---
## Цели обработки ошибок
- Ясно и точно сообщить о наличии ошибки
	- Место
	- Тип ошибки
	- Как устранить
- Быстрое восстановление после ошибки для продолжения разбора
- Существенно не замедлять обработку корректной программы

---
## Типы ошибок
- Ошибка компиляции
	- Лексические ошибки
	- Синтаксические ошибки
	- Семантические ошибки
- Ошибки во время выполнения

---
## <!--fit--> Стратегии восстановления после ошибок
- Режим паники
- Уровень фразы
- Продукции ошибок
- Глобальная коррекция

---
## Режим паники
- При обнаружении ошибки осуществляется пропуск до обнаружения лексемы из синхронизирующего множества
- Может быть пропущено очень много символов без анализа

---
## Уровень фразы
- Локальная коррекция входного потока для продолжения работы
- Примеры:
	- Если пропущен символ `;`, его добавляют
	- 9 + "1"

---
## Продукции ошибок
- Для типовых ошибок добавляется правило грамматики.
- При применении правила регистрируется ошибка, но анализ продолжается.

---
## <!--fit--> Определение семантических ошибок
Свойства языка из лабораторного практикума:
- Объявление переменных
- Преобразование типов
- Оператор присваивания
- Структуры, ограничивающие область видимости
- Условные операторы
- Перегрузка подпрограмм
- Передача параметров в подпрограмму
