# Синтаксически управляемая трансляция

---
## Из чего состоит
- Атрибутивная грамматика (КС-грамматика + семантические действия)
- В семантических действиях описывается:
	- Семантический анализ
	- Генерация промежуточного кода

---
## Пример (1)
```
1) D → T L
2) T → int
3) T → char
4) L → L, id
5) L → id
```

---
## Пример (2)
```
1) D → T {L.inh = T.type} L
2) T → int {T.type = integer}
3) T → char {T.type = char}
4) L → {L₁.inh = L.inh} L₁, id {AddType(id.ns, L.inh)}
5) L → id {AddType(id.ns, L.inh)}
```
---
## Особенности
- Совмещения описания грамматики с этапами обработки. Есть и + и -
- Обработка исходной программы за один проход
