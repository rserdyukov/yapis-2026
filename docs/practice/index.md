# Практические занятия

Пять задач по [темам курса](../course/index.md#tema-2): от конечного автомата до
синтаксически управляемой трансляции. В каждой задаче есть теоретические сведения,
условие, 30 вариантов и разобранный пример решения. Номер варианта выдаёт преподаватель.

<div class="grid cards" markdown>

- **[Задача 1. Конечный автомат](task1.md)**

    Регулярное выражение → диаграмма переходов, детерминизация и минимизация ДКА.

- **[Задача 2. КС-грамматика](task2.md)**

    Описание языка → порождающая грамматика, деревья разбора, устранение левой
    рекурсии и левая факторизация.

- **[Задача 3. Предиктивный анализатор](task3.md)**

    Множества FIRST и FOLLOW и таблица предиктивного (LL(1)) анализатора.

- **[Задача 4. SLR-анализатор](task4.md)**

    LR(0)-пункты, диаграмма переходов и таблица SLR-анализатора.

- **[Задача 5. Синтаксически управляемая трансляция](task5.md)**

    Промежуточный код (дерево, даг, четвёрки, тройки), оптимизация и перевод
    между представлениями.

</div>
